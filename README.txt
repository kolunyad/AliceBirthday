Для моей Алисы — интерактивная книжка (15 страниц)

Откройте index.html в браузере. Интернет и установка программ не нужны.
Перелистывание: кнопки, стрелки клавиатуры или свайпы на телефоне.
Для увеличения нажмите на страницу. Есть автолистание раз в 8,5 секунды.

ВАЖНО: страница 6 временно содержит более раннюю иллюстрацию
«Тайные уголки» — итоговая подводная «Лилии у тихой воды»
недоступна как отдельный файл в рабочей папке.
Чтобы заменить, конвертируйте нужное изображение в WebP и сохраните как images/06.webp.

Публикация на GitHub Pages:
1. Создайте репозиторий и загрузите index.html и папку images/.
2. Settings → Pages → Deploy from a branch → main / root.
3. Через некоторое время сайт появится по публичному URL GitHub Pages.

Все 15 иллюстраций упакованы в images/; полностью автономно.
